# Employee Management System

This is a simple Employee Management System built with Node.js and Express. It provides RESTful API endpoints to manage employee records, including creating, reading, updating, and deleting employees.

## endpoints are as follows:
- POST /employees (Admin only): Create a new employee
- GET /employees: Get all employees
- PUT /employees/:id (Admin/HR): Update an employee
- DELETE /employees/:id (Admin only): Delete an employee
