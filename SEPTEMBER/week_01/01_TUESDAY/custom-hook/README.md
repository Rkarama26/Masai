## Custom Hook
 in this project i m getting understanding of custom hooks in react.

  A custom hook is simply a javascript function whose name start with ```use``` keyword and that may call other hooks

  In this project, I am using a custom hook called `useFetch` to fetch data from an API endpoint.

 ### Purpose - 
  - Reusability use the same hook in multiple components without repeating code.
  - Abstraction hide complex logic behind a simple API.
