## Form data handling using useReducer

From this project, I learned how to manage form state effectively using the useReducer hook in React. Instead of handling multiple useState hooks separately, I was able to store all form data (email and password) in a single state object and update it through clearly defined actions. I also understood how to implement different action types like email, password, submit, and reset to control form behavior. This helped me practice conditional rendering (showing "No details found" initially and displaying user details after submission) and also taught me the importance of handling invalid actions with proper error messages. Overall, I gained a clearer understanding of state management with reducers and how it makes complex forms more structured and maintainable.
