# Theme App - Learning useReducer Hook

In this project, I learned about the `useReducer` hook in React.

## What is useReducer?

`useReducer` is a tool in React that helps you manage and update your app’s state in a more organized way.

## Why is useReducer useful?

- When your app’s state becomes complicated, using `useState` can get messy and hard to manage.
- `useReducer` lets you keep all your state changes in one place, making your code easier to read and fix.
- It works like a manager: you tell it what happened (an action), and it decides how to update the state.

## Simple Example

Imagine you have a light switch:
- With `useState`, you just turn it on or off.
- With `useReducer`, you can handle more actions, like dimming, changing colors, or toggling, all in one place.
