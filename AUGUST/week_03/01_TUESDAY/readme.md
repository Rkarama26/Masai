## Imperative vs Declarative

 - Imperative: Writing a recipe step-by-step (“Take a cup of flour, add two eggs, stir 30 times…”).

 - Declarative: Ordering a cake from a bakery (“I want a chocolate cake”), letting the bakery decide the steps. 
 ex. React

 - Declarative: You describe what you want to see (e.g., a list of items), and React takes care of the how (e.g., rendering the list, updating it when items change).

 - react: is only declarative.

 - javascript: is both imperative and declarative.

 ## SPA (Single Page Application)

 - A web application that interacts with the user by dynamically rewriting the current page, rather than loading entire new pages from the server.

 - WHAT IS SPA ? 
   - A Single Page Application (SPA) is a web application that loads a single HTML page and dynamically updates that page as the user interacts with the app.
   - SPAs use AJAX requests to fetch data and update the UI without requiring a full page reload.
   - This approach results in a more fluid user experience, similar to a desktop application.

- WHAT IS THE BENEFIT OF SPA?
   - Improved performance: SPAs load content dynamically, reducing the need for full page reloads and improving load times.
   - Enhanced user experience: SPAs provide a more seamless and responsive interface, similar to native applications.
   - Simplified development: SPAs often use a single codebase and can be easier to maintain and scale.

- SSR (Server-Side Rendering) vs CSR (Client-Side Rendering)

   - SSR: The server generates the full HTML for a page on each request, which can improve SEO and initial load times.
   - CSR: The client (browser) downloads a minimal HTML page and uses JavaScript to render content dynamically, which can lead to faster subsequent interactions.
