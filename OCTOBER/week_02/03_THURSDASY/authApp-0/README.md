#  Node.js Email Sender App

A simple Node.js + Express application to send an email to two recipients using **Nodemailer**.

---

##  Features

- Single route: **`/sendemail`**
- Sends an email to:
  - Your own email
  - **venugopal.burli@masaischool.com**
- Email content:
  > "This is a testing Mail sent by NEM student, no need to reply."

---

##  Tech Stack

- Node.js  
- Express.js  
- Nodemailer  
- dotenv (for environment variables)
