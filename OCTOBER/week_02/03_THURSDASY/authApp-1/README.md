#  User Authentication API (Signup, Login & Forgot Password)

A secure **Node.js + Express** API for user authentication with signup, login, and forgot password functionality.  
All user routes are accessible via the base path **`/user`**.

---

##  Features

- 🧾 User registration with **hashed passwords** using bcrypt  
- 🧍 Ensures **unique email** per user  
- 🔑 Secure login with **JWT-based authentication**  
- 🔁 Forgot password with **secure reset link via email**  
- ⚙️ Environment variables handled via **dotenv**

---

## 🛠️ Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB + Mongoose**
- **bcrypt** for password hashing
- **jsonwebtoken** for JWT creation
- **nodemailer** for sending reset emails
- **dotenv** for configuration management
